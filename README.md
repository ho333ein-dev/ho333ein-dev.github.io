# امنیت دید — AMANIAT DID

فروشگاه اینترنتی تجهیزات حفاظتی و نظارتی: دوربین مداربسته، دزدگیر، اعلام حریق،
تجهیزات شبکه، برق خورشیدی و تجهیزات جانبی اضطراری.

سایت با **React 18 + Vite 5** ساخته شده، کاملاً **راست‌به‌چپ (RTL)** و فارسی است و
فونت **وزیرمتن** به صورت self-hosted (بدون CDN خارجی) استفاده می‌شود.

## استقرار روی GitHub Pages

آدرس نهایی سایت:

```
https://ho333ein-dev.github.io/amaniat-did/
```

### چرا سایت زیر یک زیرمسیر کار می‌کند

GitHub Pages پروژه‌ها را روی `https://<user>.github.io/<repo>/` سرو می‌کند، نه روی
دامنهٔ ریشه. بنابراین:

- در `vite.config.js` مقدار `base` روی `/amaniat-did/` تنظیم شده است تا همهٔ
  فایل‌های CSS، JS، فونت و تصویر با پیشوند درست درخواست شوند.
- در `src/App.jsx` روتر با `basename={import.meta.env.BASE_URL}` بالا می‌آید تا
  لینک‌های داخلی یک سطح بالاتر نروند.
- فایل `public/.nojekyll` جلوی پردازش Jekyll را می‌گیرد (بدون آن پوشه‌های با
  پیشوند `_` نادیده گرفته می‌شوند).
- چون Pages سرورِ بازنویسی مسیر ندارد، `scripts/make-404.mjs` بعد از هر بیلد یک
  کپی از `dist/index.html` را با نام `dist/404.html` می‌سازد. با این کار باز
  کردن مستقیم آدرس‌های عمیق مثل `/amaniat-did/product/...` هم درست بالا می‌آید.

اگر بعداً سایت روی دامنهٔ اختصاصی یا ریپوی `<user>.github.io` منتقل شد، کافی است
`VITE_BASE_PATH=/` را ست کنید؛ مقدار پیش‌فرض داخل `vite.config.js` قرار دارد.

### روش اول — استقرار خودکار با GitHub Actions (پیشنهادی)

فایل `.github/workflows/deploy.yml` از قبل آماده است. کافی است کد روی شاخهٔ
`main` پوش شود؛ بعد از آن در هر پوش، سایت خودکار بیلد و منتشر می‌شود.

```
git push origin main
```

نکته: مرحلهٔ `actions/configure-pages@v5` با `enablement: true` اجرا می‌شود و
بار اول خودش GitHub Pages را برای ریپو فعال می‌کند — نیازی به تنظیم دستی در
`Settings → Pages` نیست.

پیشرفت را می‌توانید در تب **Actions** ریپو ببینید. شاخهٔ منتشرشده `main` است و
خروجی از آرتیفکت `dist` منتشر می‌شود.

### روش دوم — انتشار دستی روی شاخهٔ gh-pages

اگر ترجیح می‌دهید بدون Actions منتشر کنید:

```
npm run deploy
```

این دستور ابتدا بیلد می‌گیرد و بعد پوشهٔ `dist` را با `gh-pages` روی شاخهٔ
`gh-pages` می‌فرستد. در این حالت باید در `Settings → Pages` گزینهٔ
**Deploy from a branch** و شاخهٔ `gh-pages` انتخاب شود.

## اجرای محلی

```
npm install
npm run dev          # http://127.0.0.1:5173
```

بیلد تولیدی:

```
npm run build        # خروجی در dist/  (شامل 404.html و .nojekyll)
npm run preview:dist # سرو کردن dist روی http://localhost:4173
```

## ساختار پروژه

```
amaniat-did/
├─ .github/workflows/deploy.yml   استقرار خودکار روی GitHub Pages
├─ public/                        فایل‌های استاتیک، عیناً کپی می‌شوند
│  ├─ .nojekyll                   غیرفعال کردن Jekyll
│  └─ assets/
│     ├─ fonts/                   وزیرمتن (self-hosted)
│     └─ images/                  تصاویر محصولات، بنرها و اسلایدهای هدر
├─ scripts/make-404.mjs           ساخت 404.html برای مسیرهای عمیق SPA
├─ src/
│  ├─ components/                 کامپوننت‌های مشترک (هدر، فوتر، اسلایدر خانه)
│  ├─ data/                       داده‌های محصولات، دسته‌بندی‌ها و مطالب
│  ├─ lib/                        سبد خرید و توابع کمکی
│  ├─ pages/                      صفحات مسیر‌دار
│  ├─ App.jsx                     تعریف مسیرها
│  ├─ main.jsx                    نقطهٔ ورود
│  └─ styles.css                  استایل سراسری
├─ index.html
├─ package.json
└─ vite.config.js
```

## یادداشت‌ها

- **بدون درگاه پرداخت.** سایت کاتالوگ و استعلام قیمت است؛ خرید نهایی از طریق
  تماس تلفنی انجام می‌شود.
- تصاویر محصولات دارای واترمارک پایین-چپ هستند تا از دید موتور جست‌وجو، دارایی
  اختصاصی این سایت محسوب شوند.
- `prefers-reduced-motion` رعایت شده است: با فعال بودن این تنظیم در سیستم کاربر،
  همهٔ انیمیشن‌ها (از جمله Ken Burns اسلایدر) خاموش می‌شوند.
